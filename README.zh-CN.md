# dsh-aigc

**给 DeepSeek Harness 装上画笔：一句话出图（文生图 / AI 作图）、一句话出歌（文生歌 / Suno 音乐生成）。** 插件免费装，按次从虾盘云钱包扣费。

别人给 DSH 装眼睛（`dsh-vision` 一类让你"看懂图"），这个插件给 DSH 装**画笔**——直接产出图片和音乐文件。

**插件免费装，用一次扣一次虾盘云钱包余额。**

不用注册 API Key、不用订阅。第一次调用自动绑一个钱包（余额 0），微信扫码充值，之后每张图、每首歌都从这笔余额里扣。**密钥就是钱包**：把它备份好，换台电脑填进去，余额跟着走。

## 三个工具

| 工具 | 干什么 |
|---|---|
| `dsh_aigc_image` | 文生图，返回本地文件路径。尺寸可写像素（`1024x1536`）或比例（`3:4`，自动换算） |
| `dsh_aigc_music` | 文生歌（带人声/歌词）或纯音乐。异步：提交 → 轮询 → 下载，通常一次出 2 首 |
| `dsh_aigc_wallet` | `status` 看状态 / `balance` 查余额 / `adopt` 填入已有密钥 / `bind` 绑全新空钱包 |

## 安装

```bash
dsh plugin --profile <名字> add github:hfshfg/dsh-aigc
```

装完直接调任意工具。首次调用会绑钱包并把充值链接给你。

## 钱包的几条硬规矩（都是故意的）

- **服务端不认的密钥，绝不悄悄换掉。** 密钥失效时让你 `adopt` 一把有效的，而不是自动绑一个新的空钱包——否则旧余额就被甩在服务端了。
- **只用只读接口验活。** 用 `/api/pricing`（不计费）判断密钥是否被接受；**绝不用一次真实生成去"测试"密钥**，因为余额为 0 的新密钥永远测不通。
- **`bind` 必须显式。** 它绑的是余额 0 的新钱包；旧余额仍在服务端，用旧密钥 `adopt` 能找回。
- **不做硬件指纹派生。** 凭证由服务端随机签发；设备指纹不是凭证。

## 与相近插件的区别

| 插件 | 做什么 | 与我们的关系 |
|---|---|---|
| `dsh-vision` / `dsh-vision-toolkit` | **读图**：把图片喂给文本模型看 | 互补。它让你看懂图，我们让你产出图 |
| `dsh-emoji` | 给回复加 emoji | 无关 |
| `DSH OpenPencil` | 设计画布，人机协作排版 | 互补。它管设计稿，我们管素材生成 |
| **本插件** | **生成**：文生图 + 文生歌，落成本地文件 | 生态里目前唯一做"生成"的 |

## 已知限制

- **必须有钱包余额**。余额为 0 或负数时，`/v1/*` 会返回 `Invalid token`（不是密钥坏了），充值即可。插件不会替你垫付，也不会自动换密钥。
- **模型由上游决定**。插件不维护模型清单，实际可用模型以 `/api/pricing` 为准；模型下线不会提前通知。
- **音乐是异步任务**，通常 1–5 分钟，最长轮询 10 分钟；超时后可用同一任务号继续查，不会重复扣费。
- **中文长句、二维码、精确 LOGO 文字**扩散模型写不对（行业通病）。带字海报建议先生成背景再叠字。
- **不做内容合规审查**。生成内容的使用责任在调用方。

## 模型

模型 id 会变，插件**不维护清单**。想看你的账号能调什么：

```bash
GET {baseUrl}/api/pricing
```

写这份文档时该接口返回 **179 个模型**，其中图像类有 `gpt-image-2.5-sunburst`、`seedream-4-5`、`gemini-3-pro-image`、`wan2.7-image-pro`，音乐类有 `suno_music`、`suno_concat`。

## 排错

| 现象 | 真实原因 | 怎么办 |
|---|---|---|
| `/v1/*` 报 `Invalid token`，但 `/api/pricing` 返回 200 | 钱包余额为 0 或负数——计费接口会拒 token，管理接口不拒 | 充值后重试 |
| 生成时报「余额不足」 | 同上，在生成那一刻被拦下 | 用充值链接充 |
| 密钥确实被 rotate 过 | 旧密钥立刻作废，余额还在钱包上 | `adopt` 当前那把 |
| 音乐任务超时 | 上游还在生成 | 用同一个任务号稍后再查 |
